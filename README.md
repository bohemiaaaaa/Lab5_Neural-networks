# Лабораторная работа №5: Обработка текстов с помощью рекуррентных и сверточных нейронных сетей

## Цель работы
Изучить и применить методы обработки последовательных данных с использованием рекурррентных (RNN, GRU, LSTM) и одномерных сверточных нейронных сетей (Conv1D) для решения задач классификации текстов. Освоить токенизацию, создание последовательностей, применение Embedding слоёв, а также анализ влияния гиперпараметров на качество моделей.

## Задачи работы

### Задание Lite (PyTorch + TensorFlow)
Реализовать и обучить нейронную сеть для классификации текстов 6 русских писателей (Макс Фрай, О. Генри, Рэй Брэдберри, Клиффорд Саймак, Стругацкие, Булгаков). Провести эксперименты:

| № | Эксперимент | Параметры |
|---|-------------|-----------|
| 1 | Базовый | VOCAB_SIZE=20000, WIN_SIZE=1000, WIN_HOP=100 |
| 2-4 | Влияние словаря | VOCAB_SIZE=5000, 10000, 40000 (WIN_SIZE=1000, WIN_HOP=100) |
| 5-6 | Влияние окна | WIN_SIZE=500/WIN_HOP=50, WIN_SIZE=2000/WIN_HOP=200 (VOCAB_SIZE=20000) |

### Задание Pro (TensorFlow)
Реализовать и обучить нейронную сеть для диагностики 10 заболеваний по симптомам:
- Аппендицит
- Гастрит
- Гепатит
- Дуоденит
- Колит
- Панкреатит
- Холицестит
- Эзофагит
- Энтерит
- Язва

**Целевой результат:** правильное распознавание 6 и более заболеваний из 10.

### Задание Ultra Pro (TensorFlow)
Реализовать и обучить нейронную сеть для классификации 20 русских писателей:
- Лесков, Носов, Тургенев, Грибоедов, Катаев, Достоевский, Гоголь, Каверин, Лермонтов, Беляев, Чехов, Пастернак, Пушкин, Горький, Гончаров, Шолохов, Куприн, Булгаков, Васильев, Толстой

## Технологии

- **Фреймворки:** PyTorch, TensorFlow / Keras
- **Библиотеки:** NumPy, scikit-learn, Matplotlib, gdown
- **Типы слоёв:** Embedding, GRU, LSTM, Bidirectional, Conv1D, MaxPooling1D, GlobalMaxPooling1D, SpatialDropout1D, Dense, Dropout
